# Privacy Manifest

## Included

- Generalized Python and SQL implementation patterns
- Dependency declarations
- Portfolio summaries describing methods, decisions, and transferable skills
- Generic field names and example folder contracts
- Synthetic-fixture tests for the supplier coverage and catalog transformation examples
- Synthetic-fixture tests for the research throughput lineage example

## Excluded

- CSV, XLSX, Parquet, DuckDB, and JSON data files
- Generated reports and exports
- Customer, supplier, manufacturer, client, and business-entity names
- Internal IDs, URLs, source-system exports, and operational status data
- Private notebooks, screenshots, and team-specific notes
- Archived scripts that were superseded or tied to a single engagement
- Persistent entity-resolution libraries and operational mapping decisions

The export is intentionally code-and-method focused. It is not a runnable copy of the private analysis workspace until a user supplies their own compatible inputs.
