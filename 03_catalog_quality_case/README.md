# Catalog Quality Case

A compact data-quality case study for a messy multi-supplier catalog.

The included scripts show two complementary problems:

- Standardize inconsistent supplier/manufacturer names and enrich catalog rows from a master dimension.
- Deduplicate catalog records using business-relevant identity fields rather than a blind row drop.

The original challenge data and notebook are excluded. The code is retained because the reasoning pattern transfers to supplier onboarding, product catalogs, and master-data management.

## Skills demonstrated

Pandas transformations, lookup design, foreign-key validation, duplicate rules, match-rate diagnostics, and communicating assumptions before changing data.
